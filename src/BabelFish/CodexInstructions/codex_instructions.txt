The goal is to implement the API call in APIClients/OrionMatchAPIClient for the lambda function in CodexInstructions/PatchMatchChild

Perform the following steps for each function:
1. Create the data struction of the API response in DataModel under the correct subdir. Skip this step if the DataModel already exists

2. Create the response wrapper for the response data structure in Responses/OrionMatchAPI (Skip if already exists)

3. Create Requests/OrionMatchAPI/{FunctionName}AuthenticatedRequest.cs following the convention of other Authenticated requests in that folder
When writing the Request, make sure to set the correct SubDomain (AUTHAPI versus API). 
-Note that PatchMatchChild has the match child passed as the body

4. Create Responses/OrionMatchAPI/PatchTournamentMemberAuthenticatedResponse.cs following the convention of other Authenticated responses in that folder

Note for the Requests/Responses, do NOT create abstract Response/Request classes

5. Add {FunctionName}AuthenticatedAsync function(s) to APIClients/OrionMatchAPIClient.cs following the convention of other API call functions in that file. 

6. Create/write new test functions to test the function created in OrionMatchAPIClient.cs in tests/BabelFish.Tests/DataModel/OrionMatchTests/VirtualMatches/{FunctionName}Tests.cs 

If an enum for a request parameter already exists, use it and use EnumHelper.MemberValue to convert to query string (not applicable in this case)
